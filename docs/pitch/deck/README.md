# Pitch deck

The current farmagusta pitch deck, 15 slides.

| File | What it is |
| --- | --- |
| [farmagusta-pitch.pdf](farmagusta-pitch.pdf) | The deck as a PDF, 1920 × 1080 slides |
| [farmagusta-pitch.html](farmagusta-pitch.html) | The same deck as one HTML page; open it in a browser |
| [speaker-notes.md](speaker-notes.md) | What to say on each slide, with the sources |
| [references.md](references.md) | Numbered source links, claim mapping and strategy alignment |
| [assets/](assets/) | Photos and app screenshots used in the deck |

The slides cover the participation gap (2–5), the patient journey (6–8), the proposed delivery service (9–10), the nurse workspace (11–12), the cost scenario (13), limitations (14), and the closing message (15). Supporting detail and sources are in the speaker notes.

The theme follows the website: Poppins headings, Open Sans body text, HUS blue, pale grey surfaces and amber for flagged figures. The photo cover keeps the website’s turquoise brand dot. Fonts are bundled in `assets/fonts/` with their SIL Open Font License notices, so the deck opens without a font download.

Evidence claims use numbered citations with short linked footers; full references and limits are in `references.md`. Prototype behavior and proposed hardware are labelled separately from research evidence. The robots, the lab and the bookings in the demo are simulated, and the people are invented.

The earlier deck, `../farmagusta-screening-attendance.pptx` and its PDF, is kept for reference.

Photos: the kerb photo of the S-kaupat robot is CC0 from Wikimedia Commons; the cover photo is an S Group press image (STT Info).
