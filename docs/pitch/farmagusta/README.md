# Farmagusta video assets

Final invitation props for the pitch video, addressed to Aino K.

- [Screening invitation](Farmagusta_Screening_Invitation.pdf): one-page letter with a larger QR section and navy and teal accents.
- [Email sample](Farmagusta_Email_Sample.html): matching HTML email with an embedded QR image.
- [Plain-text email](Farmagusta_Email_Sample.txt): subject, sender name and copyable body.
- [QR image](Farmagusta_Mock_QR.png): standalone image used in the letter and email.

The QR code and email button point to `https://farmagusta.example/demo`, a reserved example address. Replace both with the deployed app URL before a working scan is needed. The HTML uses a data URI for the QR preview; email clients that block embedded data images need a hosted image or a CID attachment.

These are fictional video props, not HUS-issued invitations or a production screening service. Clinical and operational steps are illustrative.
