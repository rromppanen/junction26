# Farmagusta pitch video clips

14 Farmagusta/Junction video files (83.7 MiB): graphics, a screen recording and working edits. Files were copied without recompression.

The raw takes (`source/`, 20 iPhone clips) and the five prepared robot clips (`selects/`) were removed before submission to keep the repository small. They remain in git history and Git LFS; the EDL and timeline files still name them.

- `edits/`: four working assemblies. Start with `04-full-demo-scaffold-v01.mp4`; it is a rough edit with placeholder sections, not a finished submission.
- `project/graphics/`: nine title and transition video assets.
- `screen-recordings/`: nurse demo recording.
- `project/`: available timeline, EDL, narration, shot list and selection notes.
- [Editing notes](EDITING-NOTES.md): context for the working cut.
- [Manifest](manifest.csv): file sizes and SHA-256 checksums.

## Download

Video files use Git LFS. With Git LFS installed, clone the repository and run `git lfs pull --include="docs/pitch/farmagusta/video/**"`. A ZIP download may contain pointers instead of videos.

The working edit and the editing notes describe which clips still need editing.
