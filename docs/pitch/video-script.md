# 2:00 video script

The voice-over is about 260 words, which takes about 2:00 at a calm pace. Record the screens first, then the voice. Cut the screen to the voice, not the other way round. If you run long, cut the lines marked *(cut if long)*.

Before you record, check each number against the live app's start page, which shows its source.

**Setup**
- **Browser.** Full screen at 1920×1080, zoom 110%, light theme, no bookmarks bar.
- **Demo state.** Open `/demo` and press reset, so Aino starts at "Your bowel screening kit".
- **Cursor.** Move it slowly and click once. Don't scroll while the voice is saying a number.
- **Title cards.** Use deck slides 1, 2 and 12, exported from the PDF.
- **Music.** Optional: low, no lyrics, fading out under the last line.

## Notes for the voice

- **Delivery.** Say it, don't read it. Pause for half a second after "one in five".
- **Demo label.** The video must show the line "Demo: invented people; the robot, lab and bookings are simulated." It is on every page; keep it in frame once.
- **Claims.**
  - Don't claim it shortens waits or saves lives. That is what the pilot measures.
  - Don't claim real robots, real lab integration or AI the demo doesn't show.
