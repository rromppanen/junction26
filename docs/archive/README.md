# Archive: the earlier Läpi direction

These files describe the team's first direction, not the product we submit. Keep them for history only. For the current project, read the [README](../../README.md) and [docs/idea.md](../idea.md).

## What changed

From Friday evening to Saturday 14.11.2026, the team built **Gap Radar**, renamed **Läpi** on Saturday. It was a dashboard for a wellbeing services county. It showed the county where people drop off the colorectal screening pathway, compared costed options and printed a board memo.

On Saturday the team switched to **farmagusta**. farmagusta is a service for the person invited to screening and for the screening nurse: a guided home test in nine languages, a robot that collects the sample from the door, and a nurse board that flags everyone who falls behind. The Läpi pages are no longer in the app on `main`.
