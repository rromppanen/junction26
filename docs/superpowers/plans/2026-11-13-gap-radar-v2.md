# Gap Radar v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise Gap Radar's AstraZeneca score feature by feature: locate where the gap starts, size what closing it takes, show who is left behind inside a county, point to a peer county to learn from, and hand a county a Finnish board memo and a "start measuring" kit.

**Architecture:** Each feature is a pure, unit-tested module in `web/src/lib/` that computes from `Dataset` (no AI numbers), plus one section on the county page. Gemini only gets the new computed facts as extra input. New data comes from the existing Sotkanet ingest, extended with municipality rows and equity indicators.

**Tech Stack:** Next.js 15 (App Router) + TypeScript, Vitest, Sotkanet REST, Gemini (`@google/genai`), Context.dev (`web/src/lib/context.ts`).

**Spec:** [docs/superpowers/specs/2026-11-13-gap-radar-design.md](../specs/2026-11-13-gap-radar-design.md), extended by [docs/challenge.md](../../challenge.md) (criteria, Goal 2/3 targets) and the AstraZeneca talk themes in [docs/context/README.md](../../context/README.md): equity across public vs private/occupational routes, screening gaps for language minorities and low health literacy, and treatment delays.

## Global Constraints

- Node 22 (`web/.nvmrc`); run commands with `PATH=/Users/Daniel/.nvm/versions/node/v22.23.4/bin:$PATH`.
- No new npm dependencies.
- Every number on screen comes from `Dataset` or a pure function of it; Gemini never produces numbers (validator enforces this).
- Public aggregate data only; no personal data.
- Every claim shows a source (Sotkanet id, strategy/roadmap page, or `live:<n>`).
- Correlations across municipalities are described as area-level associations, never as facts about individuals.
- Feature freeze Sat 14.11 at 22:00. Each task ships on its own: tests green, typecheck clean, page loads, commit.

## Review Focus

- A county with no value for an indicator or year: every new section shows "no data", never `NaN` or a crash.
- Tiny municipalities (under 2,000 inhabitants) swing wildly: exclude them from rankings and correlations and say so.
- Åland has no Finnish screening data and publishes in Swedish: sections must degrade, not error.
- Gemini down or rejected: the deterministic fallback brief must still mention the new facts (pattern, people-to-target).
- Opening a county page twice must not call Gemini twice within 10 minutes (cost and rate limits during the demo).
